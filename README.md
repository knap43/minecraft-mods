# minecraft-mods

| Mod | Loader | Minecraft | Summary |
|---|---|---|---|
| [Help Wanted](help-wanted/) | NeoForge | 1.21.1 | A notice board that draws an unemployed villager to your base every few days |
| [Arrow Utilities](arrow-utilities/) | NeoForge | 1.21.1 | Arrows stay lodged in mobs and drop when they die; 2D Projectiles–compatible |
| [Reverse Wheel](reverse-wheel/) | NeoForge | 1.21.1 | Mouse wheel scrolls the hotbar the other way (client-only) |
| [Photo Mode](photo-mode/) | NeoForge | 1.21.1 | Freecam photo mode with world freeze, depth of field and isometric view (client-only) |
| [Hold to Sprint](hold-to-sprint/) | NeoForge | 1.21.1 | Sprint only while the sprint key is held; no double-tap sprinting (client-only) |

Each mod lives in its own folder with its own Gradle build and workflow. Releases are tagged `<mod>-v<version>`, e.g. `help-wanted-v1.0.0`.
